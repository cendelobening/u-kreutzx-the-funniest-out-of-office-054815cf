An entry for the make.fun bounty "The Funniest Out-of-Office": a single line of auto-reply gold. The joke is that the inbox itself has clocked out and is doing a better job of ignoring everyone than its owner ever managed. The entry line is:

> I'm out of office — my inbox went on vacation too, and it's ignoring you even better than I ever could. Back Monday, probably.

## Run it

```sh
python3 main.py
```

This writes the one-line reply to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`), with no trailing newline.
